Kalender

Wo finde ich den Link?

Google: calendar.google.com → Einstellungen → Kalender auswählen → „Privatadresse im iCal-Format“.
iCloud: Kalender-App → Kalender teilen → „Öffentlicher Kalender“ → Link kopieren.
Outlook: Einstellungen → Kalender → Freigegebene Kalender → „Kalender veröffentlichen“ → ICS-Link.

Postfach

Was ist ein App-Passwort?

Ein eigenes Passwort nur für Vertex – nicht dein normales. Gmail: myaccount.google.com → Sicherheit → 2-Faktor an → „App-Passwörter“ (Server imap.gmail.com). iCloud: appleid.apple.com → App-spezifische Passwörter (imap.mail.me.com). Outlook: account.microsoft.com → Sicherheit → App-Kennwörter (outlook.office365.com). Vertex liest nur und legt Entwürfe ab – er sendet nie selbst.
